## Description
Team Zen (SIH-S-B1-060), Smart India Hackathon 2026.
Problem statement SIH26168 (ISRO): AI-ML based Intelligent Dead Reckoning system for seamless navigation.

When GPS drops in a tunnel, an underground ramp or a dense street, navigation apps stop updating. Our system keeps estimating vehicle position using only the phone's accelerometer and gyroscope. A small neural network learns the sensor bias, exact physics integrates it, and a GNSS/INS fusion engine hands over to and back from GPS without a visible jump. Map matching keeps the estimate on real roads. Everything runs on the phone.
